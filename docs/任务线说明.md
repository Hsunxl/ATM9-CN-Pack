# 模组入门引导任务线

**19 个章节 / 828 个任务**，独立于 ATM9 内置任务书，自成一条「科技入门教程」线。

## 这条线的定位（先说清楚）

- **它是一条自制辅助线，用来帮新手入门各个模组**，讲清每个模组的核心循环怎么走起来。
  不是官方内容，也不是通关必经之路。
- **可选的，不是必做。** ATM9 原本的主任务线该怎么玩还怎么玩，
  玩家可以自由探索 ATM9 本身的游戏内容，不跟着这条线走完全没问题；
  只挑某几章看、跳过、打乱顺序，都可以。
- **仅供参考。** 里面的学习顺序、搭配和产线只是「一种可行做法」，不是唯一解，
  更不是最优解——按自己的思路来完全可以。
- **欢迎指正与修改。** 发现写错、过时、讲不清楚的地方，直接提 issue 或 PR，
  注明是哪个章节（`t00` ~ `t18`）的哪个任务即可。

---

## 它解决什么问题

ATM9 的内置任务书是**按模组罗列**的：打开一看几十个章节，新手不知道先做哪个、做完了又该接什么。
这条教程线改按**学习顺序**组织——从「什么是一度电」开始，一路推到毕业：

```
t00 入门总览  →  t01 电力  →  t02 通用机械  →  t03 机械动力  →  t04 AE2
              →  t05 植物魔法  →  t06 工业先锋  →  t07 气动工艺  →  t08 存储
              →  t09 热力  →  t10 物流  →  t11 进阶科技  →  t12 末地接口
              →  t13 补充科技  →  t14 格雷科技  →  t15 匠魂  →  t16 神化
              →  t17 新生魔艺  →  t18 魔法与冒险
```

## 每章的「七要素」结构

1. **章节总览**（六边形里程碑）—— 模组定位、核心概念、解决什么问题、与其他模组如何配合、分支路线图
2. **新手入门** —— 从零第一套产线的完整路径、第一步做什么、常见误区
3. **实用技巧** —— 界面操作、快捷键、效率优化、模组间搭配
4. **方块·物品·机器大全** —— 按功能分类逐个列名 + 一句话作用 + 用法 + 进阶操作
5. **事例设施** —— 完整示例产线：布局、方块清单、接电接物流方式、产量预期
6. **机器结构（多方块）** —— 结构尺寸、方块清单、搭建顺序、激活维护要点
7. **章节结尾综合实战**（八角形里程碑）—— 把本章核心系统搭起来的实战目标

## 安装

**第 1 步**：把 `overrides/config/ftbquests/quests/chapters/` 里的 19 个 `.snbt` 复制到
整合包实例的 `config/ftbquests/quests/chapters/`。这 19 个文件是**新增**的，不会覆盖任何原版任务。

**第 2 步（必须）**：打开 `config/ftbquests/quests/chapter_groups.snbt`，
在 `chapter_groups: [ ... ]` 数组里追加一行：

```
{ id: "00C72C1FB6193A42", title: "&d科技入门教程&f" }
```

> 参照 `install/chapter_groups.追加片段.snbt`。注意行尾不要多出逗号。
> 这一步不做的话，19 个章节会因为找不到分组而不显示。

**第 3 步**：进游戏按 **Q**（或点右上角书本图标）→ 顶部出现「**科技入门教程**」标签页。

## 卸载

删掉 `config/ftbquests/quests/chapters/` 下的 `t00_overview.snbt` ~ `t18_magic_adventure.snbt` 共 19 个文件。
分组注册行留着也无害，只会显示一个空分组；想彻底清掉就把上面追加的那一行删掉。

## 质量说明

- **物品 ID 四层校验**：19 章共 923 处引用 / 701 个唯一 ID，经「资产层（models + lang）/
  数据层（data 配方·标签·进度）/ 代码层（.class 常量池）/ 脚本层（kubejs）」逐层比对，**0 个不存在**
- **依赖完整性**：865 条依赖，断链 0、孤立 0、循环 0
- **ID 唯一性**：2485 个任务/任务项/奖励 ID 无重复，全部为正数（重启不会被 FTB 重新随机生成）
- **布局**：任意两个任务最小间距 1.5（无重叠），无连线交叉、无横穿任务图标的长线
- **不影响原任务**：只替换 19 个章节文件 + 追加 1 行分组配置，ATM9 原有任务一字未改

## 兼容性提醒

任务里的物品 ID 取自 **ATM9 1.1.0**。版本差异较大时个别 ID 可能失效，
任务图标会显示成问号——点开就知道是哪个。

本教程是为 **全模组** 配置设计的。如果你在 ATM9 里关掉过某些模组，
对应章节里引用那些模组物品的任务会无法完成，跳过即可。
