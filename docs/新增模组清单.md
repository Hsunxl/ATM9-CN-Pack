# 新增模组清单

本包在**原版 ATM9 1.1.0** 之上新增 / 升级 / 停用的模组。

> ### 这份清单是怎么来的
>
> 1. 取 **官方 ATM9 1.1.0 整合包**（CurseForge 项目 715572，文件 6985843，51.4 MB），
>    解开其中的 `manifest.json`（**433 个模组工程**，逐条带 projectID / fileID）与 `modlist.html`（模组名 + 作者）。
> 2. 逐个读取本机 `mods/` 里 **446 个 jar** 的 `META-INF/mods.toml`，取 modId / displayName / version。
> 3. 两边做归一化匹配（含官方名与 jar 名不一致的情况，例如官方叫 `Tinkers Construct`、
>    `Architectury API`、`OpenBlocks Elevator`，jar 里是 `tconstruct`、`architectury`、`elevatorid`）。
> 4. **官方 433 个模组在本机全部找得到**；剩下对不上官方清单的，就是下面这些。
>
> 全部可复现，不依赖任何"文件时间戳"之类的猜测。

```bash
# 2. 本机每个 jar 的 modId

# 3. 两边归一化后取差集
```

## 需要自己动手的部分

**车万女仆的 AI 功能需要自备 API Key。** 本仓库不含任何密钥，
安装后编辑 `config/touhou_little_maid/sites/*.json` 填入你自己的即可
（支持智谱 GLM / 讯飞 / 硅基流动 / MiniMax 等）。不填也不影响游戏，只是女仆不会聊天。
