## 怎么复核

```bash
# 1. 取官方本体
curl -o atm9-1.1.0.zip "https://mediafilez.forgecdn.net/files/6985/843/All%20the%20Mods%209-1.1.0.zip"

# 2. 解出权威清单（两者各 433 条、顺序对应，可配对出 projectID <-> 模组名）
unzip -p atm9-1.1.0.zip manifest.json    # 433 条 projectID / fileID
unzip -p atm9-1.1.0.zip modlist.html     # 433 条 模组名 / 作者 / CF slug

# 3. 本机每个 jar 的 modId：读 mods/*.jar 内的 META-INF/mods.toml

# 4. 两边归一化后取差集

# 5. 查某模组的官方版本：https://www.curseforge.com/minecraft/mc-mods/<slug>/files/<fileID>
```
