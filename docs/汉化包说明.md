# 汉化资源包说明

## 这是什么

`overrides/resourcepacks/Minecraft-Mod-Language-Modpack-Converted-1.20.1.zip`

适用于 Minecraft 1.20.1 Forge 的**模组简体中文资源包**，内含约 **2107 个模组的 `zh_cn.json`**。

> 它是**可选的**：装上只是让模组界面显示中文，不影响任何玩法。
> 想看英文原名、或和其他语言包混用，随时在资源包列表里取消勾选就行。

## 质量说明（换句话说：别指望它全对）

CFPA 本体是众人协作、经过校对的质量较高的一部分；
**柠娜的补丁和 AI 补全部分没有经过系统校对**，存在误译、术语不统一、漏翻的可能。

当作辅助阅读用就好，**不建议拿它当攻略依据**。
发现明显错误的话，欢迎按下面「反馈」一节指正。

## 安装

**方式一（推荐）**：把 zip 放进整合包实例的 `resourcepacks/` 目录，
游戏内 `选项 → 资源包` 里把它移到右侧启用。

**方式二**：直接用 [I18n Update Mod](https://modrinth.com/mod/i18nupdatemod) 自动下载官方最新版，
不需要用本仓库的副本。

## 为什么仓库里放 zip 而不是散装 json

散装文件有 2000+ 个、且需要严格匹配目录结构，容易放错。zip 直接丢进 `resourcepacks/` 就能用。
需要单独某个模组的翻译，解压后按 `assets/<模组ID>/lang/zh_cn.json` 取用即可。

## 反馈与修改

- **属于 CFPA 原文部分的错误** →请反馈给上游 CFPA 项目。这里的副本只是转发，**上游修好才有意义**。
- **属于柠娜补丁 / AI 补全部分的错误** → 可以直接在本仓库提 issue 或 PR 指正，
  注明是 `assets/<模组ID>/lang/zh_cn.json` 里的哪个键即可。

欢迎指正，改完用同样的 CC BY-NC-SA 4.0 发布就行。
